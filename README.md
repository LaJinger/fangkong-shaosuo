# 防空哨所 · Air-Defense Sentry

1024 超能 Coding 周末 · WaytoAGI 全国 AI 切磋大会参赛作品（游戏赛道）

一款国防教育向的雷达哨兵网页小游戏：你是一名雷达兵，在老式 PPI 雷达屏上分辨每一个光点的身份——民航放行、友军引导、敌机拦截，误伤民航即事故。

## 玩法

- 打开页面 → 登记处上传照片或一句话描述，AI 生成你的专属哨兵全息卡
- 点击雷达上的光点，读三条线索（回波强度 / 运动特征 / 应答斑）
- 按身份处置：放行 · 引导 · 拦截反制 · 上报 ISAR 成像识别
- 波次递进：民航识别 → 敌机 → 无人机（注册/黑飞教育）→ 应答故障与伪装目标 → 直升机旋翼脉动
- 全部提示写在游戏内，无需说明文档

## 技术与致谢

- 单文件零依赖网页（Canvas 2D + WebAudio + CSS 3D），手机浏览器可玩
- 全息主角卡：视觉交互方式受开源项目 [Holo Card Studio](https://github.com/) 启发，光学层（光谱镭射/沃罗诺伊星光/深度视差）为独立移植实现
- AI 生成：OpenAI 兼容 /images/generations 接口（可配置），无 Key 时内置程序化画风
- 雷达/敌我识别/ISAR 科普内容为面向公众的简化示意，法规要点参考《无人驾驶航空器飞行管理暂行条例》
